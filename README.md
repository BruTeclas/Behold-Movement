# Behold Movement

Site de inscrições do Behold Movement, publicado em https://beholdmovement.com.br, e a automação que recebe as inscrições: planilha no Google Sheets, e-mail de boas-vindas e mensagem de WhatsApp pelo Chatwoot, tudo pelo n8n.

- `site/`: o site publicado.
- `n8n/behold-inscricao.json`: o workflow do n8n (gerado por `scripts/build-n8n.py`).
- `docs/configuracao.md`: como publicar o site, configurar o n8n e cuidar do WhatsApp.
